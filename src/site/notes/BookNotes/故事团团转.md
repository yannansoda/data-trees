# Comments
在瑞典图书馆意外地遇到这本书的繁体版，忍不住翻完了，创作真的很不容易啊。一本本熟悉的绘本唤起了许多美好的回忆，想重温《时光电影院》和去看看宜兰的几米主题广场。

# Highlights


繪本作者常被稱為插畫家，但插畫和繪本看似相近，實則有著遙遠的距離。即使繪本容納的資訊量與電影相差甚遠，其敘事方法還是比較接近電影，有角色情節故事，有情緒起伏時間流動，而且這些統統都要在創作每幅單張畫作時便要整體通盤思考的。即使是畫單張插畫的工作，我的習慣是盡可能使其有情節在畫裡面，像是一小段時空片段的濃縮。有的插畫家喜歡玩拼貼，或是在材質和技法上讓人讚嘆，有些人的插畫會走心靈意象的呈現，做很大的變形，形成風格。我的插畫不是走組構意象、挑戰構圖、色塊分配或者是實驗材質的趣味，我比較喜歡表現出像是攝影的感覺，希望我的圖畫像是某個事件的瞬間被記錄下來。要達到類似攝影的效果，必然就要有透視、有敘事、考慮故事的流動性。
簡單來說，我希望我的插畫能像一張張的照片。編繪本時，就必須把這些照片組成一部電影。繪本和電影需要有起承轉合，即使單張植圖也要有動作和故事在裡面，像是電影劇照，可以讓人看到情節的動態。

----

有詩人說過：「帶著腳鐐跳舞才眺得痛快，跳得好。」也許我就是這種充滿「自虐」人格的創作者吧。在每一次發想新的創作主題時，我會白我設計很多限制條件，有這樣的框架之後，才能激發我更多想像。

----

真實的人生，不像電影那般輕易地可以理出主線脈絡，也不像繪本這般可以清楚地看到結構，各種創作都是我們試圖理解混沌的人生而強加組織的。人生是巨大的謎語，因此我也不敢輕易地給出謎語的解答，因為我也在謎語中。所有的創作只能試著暗示，是不是我找到答案了？是不是我可以釋懷了？只能暗示，只能象徵，繪本便是象徵與暗示的創作。

人生沒有答案，謎語最後的感義似乎是解謎的過程，而非答案。創作面每人生巨大的謎語，只能叩問，只能感受，再在作品裡獨自體會滋味一二。

------

碧娜•鮑許說她的創作來源就是「恐懼」，她作品裡有愛，也是因為要對抗恐懼而需要愛。我的創作來自於「追尋」，這個追尋可能來自於進索現實中某種永遠不存在的感覺，彷彿生命永遠有一種空洞，雖然什麼都有，但好像又什麼都沒有。
人生渺渺，唯有真實的擁抱，剎那永恆。

-----

讀文章時，很像是作者對你發球打來，你得想辦法把它接下來。如果出現什麼奇特的球路，還必須有更厲害的技術把它切回去，高手過招，互相往來。你打來絕妙好球，我怎能輸呢？早期我的插畫會試圖去描述整場球賽的感覺，但我後來我喜歡就只抓那決定性的關鍵一拍，可能是一個句子，或是句子裡面的某個簡潔的概念。
當然也有時候擊篇文章讀過很多次，卻永遠沒辦法抓到這一拍，這真的是輸了，球賽過程非常難看。乾脆放棄找尋那精彩一拍的做法，改去感受事充之後的監體感聾，再把這種感覺濃縮成一個特定的畫面。
這模的比喻，你聽懂了嗎？我是否愈描愈黑。

-----

我的國家在政治上一直有兩種極端的對立，同一件事，—邊親是白的，一邊就驗是果的。一邊說是對的，一邊一定說錯。有時候真的無法判斷，什麼是真的什麼又是假的，無時無刻不考驗著大家的智戀。生活在這樣混亂的社會，每一個事件都默默無形地影響著每一個人，「懷疑真相」變成國民生活須知。如果我不是在這樣的詭異氣氛下生活，怎麼可能創作出這樣一本瘋癲的書呢？
擔心、恐懼、白目、背叛、回憶、願望、夢想都可以是創作的核心，懷疑困惑真真假假，為什麼不能？真相崩毀更是創作的超級活火山。
